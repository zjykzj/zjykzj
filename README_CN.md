### 👋 About

专注于计算机视觉的工程化落地，从模型研发、推理优化到边缘端部署。始终相信算法价值最终体现在真实场景的推理结果上。

---

### 🎯 Focus

**视觉模型**
目标检测、分割、OCR、人脸、ReID、细粒度分类。YOLO 全系列、CRNN/CTC、多模态模型——从论文到落地。

**模型工程化**
ONNX、TensorRT、Triton。剪枝、蒸馏、量化。CV 工作流工具链覆盖数据处理、模型导出、推理和评估。

**边缘端部署**
NVIDIA Jetson、华为 Ascend、算能 SOPHON、地平线、Rockchip RKNN。C++ 多路推理、模型加速、跨平台适配。

**大模型与多模态**
LLaMA-Factory LoRA 微调、指令数据与提示词工程。vLLM 高性能推理——LoRA 直挂或权重合并。OpenAI 兼容 API 评估与基准测试。
